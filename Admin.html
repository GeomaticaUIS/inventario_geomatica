Configuración de conexión con GitHub

Crea un token de tipo fine-grained con permiso Contents: Read and write limitado solo a este repositorio. El token es lo que realmente controla quién puede guardar cambios en el repo — el usuario y contraseña de arriba solo identifican quién está editando, no reemplazan al token. El token se guarda únicamente en este navegador.
